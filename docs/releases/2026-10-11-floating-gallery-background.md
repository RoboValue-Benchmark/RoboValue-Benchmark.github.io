# Home 背景墙：悬浮图片 gallery

版本标记：`v2026.10.11-1944-xjy-floating-gallery-background`

版本时间：2026-10-11 19:44（Asia/Shanghai）。

## 背景墙设计

在论文任务图片墙的基础上，将原有紫色底面与大面积彩色罩层调整为浅中性底面，让图片组成具有清晰边界和悬浮层次的 gallery。

- 图片采用 18px 圆角，裁切表面与侧边、投影分别绘制，保持照片边缘清晰。
- 侧边轻微向右下错位，露出薄薄的厚度；短阴影交代贴边层次，下方投影中间稍明显、两端自然收淡。
- 行间与图片间距统一为 16px，留出独立卡片的空间，减少阴影在间隙中连成灰色网格的感觉。
- 去掉明显的白色全框与边缘白色反光，保留低调的暗色细边。
- 底部淡出区域缩短为 40px，减少白雾对照片的遮盖；到 Overview 的顶部留白调整为 32px，暂停按钮移到淡出区域上方。
- 深色模式采用相应的侧边与投影颜色。

## 分组行进速度

行进速度按每秒移动的 CSS 像素计算，保持匀速。同组真机和仿真行同速，行间沿用交替方向；较高页面重复这些分组时，也重复相同速度。

| 行 | 分组 | 速度 |
| --- | --- | --- |
| 1、2 | Standard A | 26 px/s |
| 3、4 | Cross-Embodiment | 15 px/s |
| 5、6 | Cross-Environment | 36 px/s |
| 7、8 | Standard B | 20 px/s |

图片数量不同的行根据实际移动距离计算动画时长，使相同分组的移动速度一致。
